Capa de Enlace

Autor/a: Luz Hernández

¿Qué es la Capa de Enlace?

La Capa de Enlace es la segunda del Modelo OSI y se encarga de garantizar que la transmisión de datos entre dos dispositivos conectados físicamente sea libre de errores. Esta capa organiza los bits provenientes de la capa física en tramas (frames) y controla el acceso al medio de transmisión.

Funciones principales

  • 📦 Agrupa los bits en tramas para una transmisión ordenada.
  • 🔄 Detecta y corrige errores de transmisión.
  • 🧭 Controla el flujo de datos entre dispositivos.
  • 🔌 Gestiona el acceso al medio físico compartido.
  • 🏷️ Utiliza direcciones MAC para identificar dispositivos en la red.

Ejemplos de protocolos

  • Ethernet (IEEE 802.3)
  • Wi-Fi (IEEE 802.11)
  • PPP (Point-to-Point Protocol)
  • HDLC (High-Level Data Link Control)
  • ARP (Address Resolution Protocol)

Importancia

La Capa de Enlace es esencial para mantener una comunicación confiable entre dispositivos. Sin ella, los datos podrían perderse o llegar dañados. Gracias a sus mecanismos de control y corrección, las redes funcionan de manera estable y eficiente.
